# 🧠 Computer Vision Project Roadmap

A progressive series of 10 computer vision projects, starting from basic classification and ending in a Smart City Dashboard.

---

## 📸 Project 1: Image Classifier (MNIST/CIFAR-10)
**Goal:** Build a CNN to classify digits or small object categories.  
**Skills:** PyTorch/TensorFlow, model training, evaluation metrics, dataset handling.

---

## 🐱 Project 2: Custom Dataset Classifier
**Goal:** Collect your own dataset (e.g., pets, cars, tools) and train a classifier.  
**Skills:** Data collection, augmentation, fine-tuning pre-trained models.

---

## 🔍 Project 3: Object Detection (YOLO/SSD on COCO Subset)
**Goal:** Detect objects in images using a pre-trained detector, then fine-tune.  
**Skills:** Transfer learning, bounding boxes, anchor boxes, non-max suppression.

---

## 🧩 Project 4: Semantic Segmentation (U-Net on Medical or Street Data)
**Goal:** Label each pixel in an image with a class.  
**Skills:** Encoder-decoder architectures, pixel-wise classification, loss functions.

---

## 🚗 Project 5: Vehicle Detection and Tracking (Live/RTSP Feed)
**Goal:** Detect and track multiple vehicles across video frames.  
**Skills:** OpenCV, multi-object tracking (SORT/DeepSORT), video I/O.

---

## 💡 Project 6: OCR with Tesseract + Vision Pipeline
**Goal:** Extract and structure text from real-world images (license plates, receipts).  
**Skills:** Text detection, OCR, text post-processing.

---

## 🔒 Project 7: Face Recognition and Anomaly Detection
**Goal:** Recognize known individuals and flag unknown or unusual entries.  
**Skills:** FaceNet/ArcFace, cosine similarity, triplet loss, anomaly detection.

---

## 🌐 Project 8: Edge Inference with ONNX + TensorRT
**Goal:** Convert and deploy a model to run on edge devices or embedded GPUs.  
**Skills:** Model optimization, ONNX, TensorRT, deployment.

---

## 🧠 Project 9: Multimodal CV (Image + Metadata Fusion)
**Goal:** Predict outcomes using both image data and tabular/temporal metadata.  
**Skills:** Multimodal networks, concatenation strategies, decision-level fusion.

---

## 🏆 Project 10: Smart City Dashboard (Final Showcase)
**Goal:** Deploy a vehicle/pedestrian monitoring system with:
- Object detection
- Real-time tracking
- License plate OCR
- Anomaly detection
- Alerts and a live dashboard  
**Skills:** Integration, backend APIs, visualization, CI/CD for ML

---
